# Execution record

The scientific protocol in `protocol.json` was saved before fitting models or evaluating attacks. The official train/test split, policy library, model-selection rules, sample sizes, exploration levels, attack budgets, metrics, main seeds, and supplementary ESLB budget were not changed after observing outcomes. This is a timestamped local protocol, not an externally registered study.

1. Five mathematical unit tests checked exact edit correction against exhaustive enumeration, continuous score envelopes, the binary active-branch identity, tiny attack problems against exhaustive search, and DR expectations / shrinkage bias and moment bounds.
2. An initial one-seed-per-setting smoke run used the active-branch attack and componentwise envelopes. It took 56.55 seconds. Before the main run, an L1 relaxation and checked dual bound were added for nominal affine gates. This improved attack certification and avoided unnecessary integer searches; it did not change any defender, metric, candidate, or data distribution.
3. The final timing run used seeds 9000–9009 in each of four settings. It completed 40 logs and 4,680 decision evaluations in 109.49 seconds with four worker processes. These seeds are excluded from main inference. Its original source is retained as `results_timing/experiment_used.py`.
4. Before launching main seeds 10000–10099, two recording changes were made: save the LP dual multipliers for independent audit, and correct the per-worker `independent_logs` metadata from the global four-cell count to the actual cell count. Neither changes decision or attack logic. The combined timing metadata correctly reports 40 logs; its individual worker records incorrectly report 40 rather than 10. Read those fields using this correction.
5. The ESLB supplement uses the first ten main seeds, not additional independent evidence. It ran separately in 238.04 seconds, including the pre-specified higher Monte Carlo checks. The supplement's decisions and the affine adapter were audited independently.
6. The main grid contains 400 independent fresh logs, 100 per (sample size, exploration) setting. Each log is reused across three declared attack budgets, thirteen rules, and three attack conditions: 46,800 decision evaluations. These evaluations must not be treated as 46,800 independent trials.
7. After three main cells completed, the remaining n=5,000, gamma=0.2 cell was restarted as four disjoint 25-seed partitions to use the idle workers. The same seeds 10000–10099 and unchanged scientific/attack configuration were used. The partial original attempt is excluded rather than combined with the rerun. The reported overall wall time includes the partial attempt. `finish_main.py` records and merges this execution schedule; ordinary reproduction can use `run_parallel.py` without repartitioning.

Adaptive search has a one-second limit per integer optimization subproblem, up to twelve competitor-cut iterations and three starting branches. Reaching this limit is allowed by the protocol and does not imply robustness. The output preserves the gap between a feasible attack and an all-real-edit utility certificate. Reporting that gap is part of the experiment, not a reason to relabel a partial search as a complete optimizer.

The scope is the full pre-specified E2 OptDigits replay grid. It does not include the future synthetic ablations, additional datasets, active-data-collection methods, or a paper-acceptance claim.
